# Blackjack
Enjoy a simple game of Blackjack!

#### Note: Running on Linux/Ubuntu is recommended. Wasp runs into issues running on Windows WSL when in a Windows file system directory. Launch WSL with the command `wsl.exe --cd ~` to launch into the linux directory and not the Windows file system.

## Install steps
Run the following commands to install and start the application:  
`git clone https://github.com/Toysoldier34/Blackjack.git`  
`cd Blackjack/blackjack`  
`npm i`  
`wasp db migrate-dev`  
`wasp start`
